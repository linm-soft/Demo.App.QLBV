📱 Workflows Supported

1. Support Ticket Management

Complete workflow from ticket submission through triage, assignment, resolution, and closure with approval mechanisms.

2. Task Assignment & Management

Three assignment strategies:

  • Direct Assignment - Manager assigns to specific staff
  • Self-Pick - Staff choose from task pool
  • Team Assignment - Tasks assigned to teams

🛠️ Technology Stack

  • Frontend: React, TypeScript, Vite
  • Backend: .NET Core, C#
  • Database: SQL Server (planned)
  • Real-time: SignalR
  • Deployment: GitHub Pages, Docker
