🚀 Quick Start - QLCV Y Khoa

Get started with QLCV Y Khoa in just 30 seconds!

📱 Try the Demo

Option 1: Static HTML Demo

The fastest way to see the application:

  1. Visit the Static HTML App (or app/index.html)
  2. Click on any screen you want to explore
  3. Use the demo login buttons to test different user roles

Demo Accounts:

  • Staff: Đinh Bộ Lĩnh → Staff Dashboard
  • Manager: Trần Quản Lý → Manager Dashboard
  • Admin: Admin User → Full Access

Option 2: React Web Application

For the full modern experience:

  1. Visit the React Web App
  2. Log in with demo credentials
  3. Explore all features with live interactions

💻 Local Development

Run Static HTML Locally

cd app
python -m http.server 8000

Then visit: http://localhost:8000

Run React App Locally

cd src/web
yarn install
yarn dev

Then visit: http://localhost:3000

Run Documentation Locally

cd docs
bundle install
bundle exec jekyll serve

Then visit: http://localhost:4000/QLCV/

🔧 For Developers

Project Structure

QLCV/
├── app/              # Static HTML demo
├── src/
│   ├── web/          # React web application
│   └── bff/          # Backend for Frontend
├── docs/             # Documentation (this site)
└── .github/          # CI/CD workflows

Tech Stack

  • Frontend: React, TypeScript, Vite
  • Backend: .NET Core, C#
  • Docs: Jekyll, GitHub Pages
  • Build: GitHub Actions

Quick Commands

# Build everything
yarn build                    # In src/web
bundle exec jekyll build      # In docs

# Test locally
yarn dev                      # React dev server
bundle exec jekyll serve      # Docs dev server
python -m http.server         # Static HTML server

# Deploy
git push origin main          # Auto-deploys via GitHub Actions
