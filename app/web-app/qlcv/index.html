Tính Năng Đã Implement

  • Login Screen - với quick demo accounts (Staff/Manager/Admin)
  • Bảng Điều Khiển Nhân Viên - Thống kê, danh sách công việc, tác vụ nhanh, thông báo hoạt động
  • Bảng Điều Khiển Quản Lý - Cảnh báo SLA, khối lượng công việc nhóm, phê duyệt, biểu đồ
  • Danh Sách Phiếu Yêu Cầu - Lọc, sắp xếp, chỉ số SLA, phân trang
  • Danh Sách Công Việc - Hiển thị List & Kanban, kéo thả, theo dõi tiến độ, checklist, bảng ghi thời gian
  • Công Việc Chờ Nhận - Chợ tự chọn công việc với ghép khớp kỹ năng
  • Modern UI - Responsive, professional design với CSS variables
🚀 Quick Start: Click "Bắt Đầu Demo" để xem login screen, sau đó chọn quick login button để vào dashboard. Không cần setup gì!

Electron Desktop App

Để package thành desktop application cho demo chuyên nghiệp:

cd app
npm install
npm start // Test locally
npm run build:win // Build Windows .exe

📄 Xem ELECTRON_EVALUATION.md và ELECTRON_SETUP.md để biết thêm chi tiết.

Tech Stack: HTML5, CSS3, JavaScript, Font Awesome, Chart.js
